# GLOBOCAN source-method transitions: public release staging

This directory is prepared for the public GitHub repository and Zenodo release. It contains source code, derived aggregate tables, figure data, bibliographic metadata and retrieval instructions. It excludes bulk GCO files, reviewer-level data, country keys, adjudication rationales and publisher PDFs.

Release tag: v1.0.0-submission

Before publication, the corresponding author must upload this directory to the authenticated GitHub repository, archive the exact tag with Zenodo, record the DOI in the journal profile and rerun the IJC integrity gate.
